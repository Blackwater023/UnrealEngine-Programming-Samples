# Unreal Engine C++ Programming Samples

This repository contains selected C++ code samples from my Unreal Engine
gameplay development work.

The samples focus on gameplay programming, technical design, and the
Gameplay Ability System (GAS).

## Examples

### Gameplay Ability System
Examples of ability granting, gameplay tags, attributes, and gameplay
ability integration.

### Character Systems
Character functionality shared between player and enemy character classes.

### Combat Systems
Gameplay code related to combat interactions, traces, and ability-driven
actions.

## Notes
These samples have been separated from their original Unreal Engine
projects and are intended to demonstrate programming style and system
architecture rather than provide a compilable standalone project.
